# 🧠💥 Quiz Bagarre !

Jeu multijoueur temps réel de culture générale au style **blocky / Roblox goofy** !
Affrontez vos amis ou des bots en **1v1**, **2v2**, **3v3** ou en **Chacun pour Soi (FFA)** jusqu'à 32 joueurs !

## 🌟 Fonctionnalités

* 💥 **Mode Chacun pour Soi (FFA / Battle Royale)** : Jouez à autant de joueurs que vous le souhaitez dans une arène solo avec classement en direct !
* 🔴 **Modes Équipes (1v1, 2v2, 3v3)** : Rouge vs Bleu avec scores d'équipe synchronisés.
* 🤖 **Bots intégrés** : Jouez en solo ou complétez le salon avec des bots goofy (*OofMaster*, *PizzaNinja*, *SkibidiCerveau*...) en 1 clic (+1 ou +5 bots).
* ⚡ **Gadgets & Power-ups** :
  * 💣 **50/50** : Fait exploser 2 mauvaises réponses.
  * 🍌 **Peau de Banane** : Secoue et fait glisser l'écran de tous vos adversaires !
  * ⚡ **Double x2** : Double vos points sur la question en cours.
  * 🛡️ **Bouclier** : Protège votre série même en cas d'erreur.
* 🔥 **Séries & Combos** : Enchaînez les bonnes réponses pour doubler vos points et voir votre avatar prendre feu !
* ⚡ **Bonus Speedrun** : Répondez en moins de 3,5s pour gagner des points supplémentaires.
* 🪙 **Monnaie virtuelle « Noob-Bux »** : Gagnez des pièces à chaque bonne réponse et victoire.
* 🧍 **Personnalisation d'Avatar ultra-complète** :
  * 12 chapeaux délires (Poulet sur la tête, Viking, Cowboy, Chapeau Hélice, Carton...).
  * 10 visages Roblox cultes dont le légendaire *Man Face*, Yeux laser, OOF...
  * 10 teintes de peau, 12 costumes, 8 pantalons.
* 💬 **Tchat & Emotes en direct** : Bulles de dialogue flottantes style BD et répliques rapides (*« OOF ! »*, *« EZ »*, *« Trop lent frérot »*...).
* 💡 **200+ questions en français avec anecdotes** : Chaque bonne réponse révèle un fait insolite « Le savais-tu ? ».
* 🎵 **Audio & Chiptune rétro** : Bruitages Web Audio (OOF authentique, explosion, glissade) et petite musique 8-bit d'ambiance.

## 🚀 Installation et Lancement

### Prérequis
* [Node.js](https://nodejs.org/) (version 16 ou supérieure)
* npm

### Installation
```bash
git clone https://github.com/zakrievahmed129-lgtm/Culture-g-n-rale.git
cd Culture-g-n-rale
npm install
```

### Lancement
```bash
npm start
```

Ouvrez ensuite votre navigateur sur **[http://localhost:3000](http://localhost:3000)** !
